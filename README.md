# Помощник МИРЭА

**Расписание, свободные аудитории и поиск времени для переноса пары — в чате, на вашем компьютере.**

Помощник работает как обычная страница в браузере, а отвечает ему ИИ, установленный на этом же компьютере. Платные подписки и регистрация не нужны, вопросы никуда не отправляются. Расписание берётся с сайта МИРЭА, входить в аккаунт университета не нужно.

## Что можно спросить

> Куда перенести пару с группой ЭФБО-01-24 на следующей неделе, чтобы не было пересечений? Аудитория нужна на Вернадского 78.

> Когда на этой неделе можно поставить отработку для ЭФБО-01-24 и ЭФБО-02-24? Подойдут 4–6 пары.

> Какие аудитории свободны завтра на 3-й паре в В-78?

> Какие у меня пары в четверг?

> Свободна ли А-214 в понедельник с 10:40 до 12:10?

**Как устроен поиск переноса.** Свободное время ищет программа, а не ИИ. Она берёт расписание преподавателя и всех групп, отбрасывает занятые пары и для каждой оставшейся проверяет свободные аудитории. Если соседняя пара преподавателя в другом корпусе, будет предупреждение. ИИ только понимает вопрос и пересказывает результат, поэтому варианты не выдуманы. Под каждым ответом есть раздел «Что я проверил» с исходными данными.

## Установка (Windows)

Нужны Windows 10 или 11, **от 8 ГБ оперативной памяти** и **5–8 ГБ свободного места** на диске.

1. Откройте меню **Пуск**, напишите **PowerShell** и откройте **Windows PowerShell**. Запускать от администратора не нужно.
2. Скопируйте команду, вставьте в окно PowerShell и нажмите **Enter**:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/Damanian638/mirea-assistant/main/install.ps1 | iex"
```

3. Подождите. Установщик сам поставит Python, программу, Ollama (в ней работает ИИ) и скачает модель ИИ — несколько гигабайт, обычно 5–30 минут. Не закрывайте окно.
4. В конце появится «Готово», откроется браузер со страницей помощника, а на рабочем столе — ярлык **«Помощник МИРЭА»**.

Модель выбирается по объёму памяти:

| Память | Модель | Скорость ответа на обычном ПК |
|---|---|---|
| 16 ГБ и больше | qwen3:8b | 15–60 с, лучше понимает сложные вопросы |
| 8–15 ГБ | qwen3:4b | 10–40 с |
| меньше 8 ГБ | qwen3:1.7b | быстро, но часто ошибается — не рекомендуется |

Первый ответ после включения компьютера самый долгий: модель загружается в память.

## Как пользоваться

- Запуск — ярлык **«Помощник МИРЭА»**. Если помощник уже работает, ярлык просто откроет его страницу.
- В **⚙ Настройках** укажите своё ФИО — тогда работают вопросы «какие у меня пары».
- Указывайте группу и неделю или даты. Корпус можно написать как «Вернадского 78» или «В-78».
- Если под фамилию подходят несколько преподавателей, помощник покажет варианты — уточните инициалы.
- **Выключить помощника** — ссылка внизу страницы. Ollama продолжит работать в фоне (её значок возле часов), это нормально.

## Важно

- Это **не официальный продукт РТУ МИРЭА**. Данные — из открытого расписания университета.
- Свободная по расписанию аудитория может быть закрыта или иметь особый порядок доступа.
- Перенос пары нужно согласовать с учебным отделом: помощник только подбирает варианты.
- Маленькая локальная модель может неверно понять вопрос. Проверяйте ответ по разделу «Что я проверил».

## Если что-то не получилось

| Что произошло | Что сделать |
|---|---|
| Установка остановилась со словом «Ошибка» | Прочитайте сообщение над ним. Повторите команду: уже скачанное не скачивается заново. |
| На странице «ИИ не запущен» | Откройте **Ollama** из меню «Пуск», подождите минуту и обновите страницу. |
| «Модель не скачана» | Повторите команду установки. |
| Ответ идёт очень долго | Закройте тяжёлые программы. На слабом компьютере первый ответ может занять больше минуты. |
| Ярлык не открывает страницу | Откройте в браузере `http://127.0.0.1:8765/`. Журнал: `%USERPROFILE%\.mirea-assistant\assistant.log`. |
| Нужно обновить | Выключите помощника на его странице и повторите команду установки. |

## Удаление

```powershell
uv tool uninstall mirea-assistant
```

Затем удалите ярлыки и, если Ollama больше не нужна, удалите её через «Параметры → Приложения». Модели лежат в `%USERPROFILE%\.ollama`.

## Для разработчиков

Данные МИРЭА берутся из [MIREA Connect](https://github.com/Damanian638/mirea-connect) (закреплённый коммит в `pyproject.toml`); ИИ — модель в [Ollama](https://ollama.com) с вызовом инструментов.

```text
src/mirea_assistant/
  slots.py    Поиск окон для переноса: пересечение расписаний по звонкам + свободные аудитории
  agent.py    Инструменты для модели, нормализация аргументов, календарь в промпте, цикл вызовов
  llm.py      Клиент Ollama (/api/chat, think=false)
  web.py      Сервер на 127.0.0.1: страница чата и API; проверка Host, Origin и JSON
  chat.html   Страница чата (без внешних ресурсов)
  cli.py      Запуск, повторный запуск, configure/model/status
  config.py   Модель и порт: ~/.mirea-assistant/config.json
```

```bash
uv venv --python 3.12
uv pip install --python .venv -e ".[dev]"
.venv/bin/python -X utf8 -m pytest -q
.venv/bin/ruff check .
.venv/bin/mirea-assistant            # нужна запущенная Ollama и модель: ollama pull qwen3:4b
```

Переменные: `MIREA_ASSISTANT_MODEL` — другая модель, `MIREA_ASSISTANT_HOME` — каталог настроек, `OLLAMA_HOST` — адрес Ollama, `MIREA_ASSISTANT_SRC` — источник пакета для `install.ps1`.
